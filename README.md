# 📊 Sales Data Dashboard Analysis (Excel)

## Overview
This project analyzes multi-year sales data to uncover trends, performance drivers, and optimization opportunities. The analysis was conducted using Microsoft Excel with a Power BI–style dashboard design.

## Objectives
- Clean and validate raw sales data
- Build KPI metrics for executive reporting
- Analyze sales trends by time, product, region, and customer type
- Design a professional dashboard using Excel best practices

## Key KPIs
- Total Revenue
- Total Units Sold
- Average Unit Price
- Total Discounts
- Total Shipping Cost
- Number of Orders

## Tools Used
- Microsoft Excel (Mac)
- PivotTables & PivotCharts
- Slicers & Filters
- Data validation and transformation techniques

## Dashboard Features
- Multi-year revenue trend analysis
- Product and regional performance breakdown
- Customer segmentation insights
- Promotion and discount impact analysis
- Executive summary and recommendations

## Key Insights
- Clear seasonal sales patterns with mid-year peaks
- Revenue concentration in high-value products
- Balanced Retail vs Wholesale customer contribution
- Opportunities to optimize promotions and logistics costs

- Convert dashboard logic to Power BI
- Add profit and margin analysis
- Automate data refresh and validation
